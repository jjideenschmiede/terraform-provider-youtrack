# Security Policy

## Supported Versions

Only the most recent release of the provider receives security updates. We encourage all users to keep the provider up to date, for example with a version constraint that allows new releases.

| Version           | Supported          |
|-------------------|--------------------|
| Latest Release    | :white_check_mark: |
| Previous Releases | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues or pull requests. Send an email to support@jj-ideenschmiede.de instead, so we can fix the problem before it becomes public.

Please include:

- A detailed description of the vulnerability and its potential impact.
- A step-by-step guide to reproduce the issue, if applicable.
- The versions of the provider, Terraform and YouTrack you used.
- Any additional information or context that might help in the assessment and resolution of the problem.

Remove permanent tokens and other confidential data from configurations, state files and logs before you send them. We appreciate your contributions to making our project more secure.
